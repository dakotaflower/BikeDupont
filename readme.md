## Map Description
This project is titled _Bike DuPont_. It is a simple interactive web map built with [Leaflet.js](https://leafletjs.com/) and depicts a popular mountain biking route in DuPont State Recreational Forest. It allows users to explore the route, with markers at the start of each new singletrack trail or gravel road. 

## Libraries and Data Sources
* HTML, CSS, and JavaScript languages are used for page structure and design 
* Text information is copied from the North Carolina Forest Service [website](https://www.ncagr.gov/divisions/nc-forest-service/state-forests/dupont-state-recreational-forest/explore-the-forest/biking)
* Basemap tiling is provided by Thunderforest ([Thunderforest OpenCycleMap](https://www.thunderforest.com/maps/opencyclemap/))
* jQuery is used to support script functionality
